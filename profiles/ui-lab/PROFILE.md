# Optional Profile: UI Lab Design Constitution V2

This profile is an optional adapter for projects that intentionally want to use UI Lab's design research. It is not required by the three universal Skills.

## When to activate

Activate only when:
- The target repository is UI Lab; or
- The user explicitly asks to apply UI Lab's design principles; or
- The target project deliberately includes this profile.

Do not impose UI Lab's visual preferences or research on unrelated projects.

## Source responsibilities

- **Refactoring UI**: visual hierarchy, spacing, typography, color, depth, and layout.
- **设计垂点**: interaction relationships, functional motion, shared interaction states, continuity, inertia, and gesture patterns.
- **Emil Kowalski**: motion quality, easing, spring, duration, frequency, interruption, and performance.
- **Apple HIG**: platform guidance and interaction conventions, applied only where relevant.
- **NN/g**: usability heuristics and cognitive load, not a normative compliance standard.
- **WCAG 2.2**: applicable Web accessibility success criteria.
- **GOV.UK Design System**: form, error, confirmation, and service-flow patterns, adapted to context.
- **web.dev**: browser rendering and performance engineering guidance.

## Required attribution

Distinguish:
- AUTHOR_EXPLICIT: a source explicitly states the principle.
- UI_LAB_DERIVED: UI Lab combines sources or derives an engineering rule.
- AI_EXPLORATION: an unverified idea proposed by an AI or developer.

Do not invent quotations, page numbers, source evidence, or claim full-source review from a link or index entry.

## Existing UI Lab documents

When working inside the UI Lab repository, read:
- `docs/DESIGN_CONSTITUTION.md`
- `docs/design-constitution/README.md`
- `docs/DESIGN_KNOWLEDGE_MAP.md`
- `docs/INTERACTION_RECIPE_ENGINE.md`

These are project-specific documents. If they are absent, the universal Skills must continue using the target project's own guidelines and general design reasoning.

## Decision priority

Follow the target project's user requirements, brand, business behavior, accessibility obligations, and technical constraints. The UI Lab profile provides additional design guidance; it does not override those constraints.
