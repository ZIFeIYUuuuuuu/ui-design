# 投票粒子与计数要有因果关系

`interaction/map-wxad-likes-3` · ORIGINAL_PRACTICE · 上游复核状态 pending

**来源定位**　[评选 24](https://wxad.design/abc/likes)

**案例或原则（UI Lab 的来源笔记）**　点亮粒子最终汇聚到票数附近，随后数字变化，用空间和时序连接投票动作与结果。

**原条目中的触发场景**　低频、用户重视的投票或提交确认

## UI Lab 扩写与适用边界

**适用条件**　低频、用户重视的投票或提交确认

**如何应用**　先让控件有按压反馈；结果真实确认后再更新计数和装饰动画。

**代价**　庆祝动效可能抢占内容，避免让数据更新依赖装饰完成。

**库中反例或不适用场景**　网络失败仍播放成功汇聚并先加票。
