# 辨认选中、焦点、禁用或错误；在主题色上读文字

只选能解释当前选择的一条。以下走查与判断分支为本次移植的教学例题，可按产品任务调整。

**怎么走**　保持 A 选中，悬停 B，再把键盘焦点移到 C；比较每种状态的文字、底色、形状和对比。

**怎样根据现场选择**　若短暂指向掩盖已选内容，拆分线索；若层级正确但文字对比不足，只调整相应颜色角色。
