# 按语境决定链接强调程度

`principle/book-link-emphasis` · ORIGINAL_PRACTICE · 上游复核状态 pending

**来源定位**　并非每个链接都需要颜色（Refactoring UI，印刷页 109）

**案例或原则（UI Lab 的来源笔记）**　正文里的链接明确可辨，链接密集 UI 可以用字重、较深前景或定位线索来控制重量。

**为什么这样做**　若每个链接都高度突出，动作层级会丢失。

## UI Lab 扩写与适用边界

**适用条件**　导航和正文链接共存

**库中反例或不适用场景**　不能要求 hover 才能识别关键链接，需保留键盘焦点
