# 用边界显明折叠面板的展开

`principle/map-wxad-springen2-4` · ORIGINAL_PRACTICE · 上游复核状态 pending

**来源定位**　[折叠面板 Collapse](https://wxad.design/abc/springen2)

**案例或原则（UI Lab 的来源笔记）**　示例让展开行获得自己的轮廓和上下间距，突出它已脱离紧密的折叠列表。

**为什么这样做**　在同一状态下改变容器边界和留白，正文可按可读节奏入场。

## UI Lab 扩写与适用边界

**适用条件**　低密度内容面板需要快速辨别当前打开项时

**如何应用**　在同一状态下改变容器边界和留白，正文可按可读节奏入场。

**代价**　放大间距有助理解组关系，也会导致下方内容位移。

**库中反例或不适用场景**　高密度后台每次展开都大幅推开浏览位置。
