# 同一索引共享运动面

`technique/map-wxad-wxad11-5` · ORIGINAL_PRACTICE · 上游复核状态 pending

**来源定位**　[多个转盘](https://wxad.design/abc/wxad11)

**案例或原则（UI Lab 的来源笔记）**　案例按相同字符索引组织同心轨道，减少需要单独运动的元素数量。

## UI Lab 扩写与适用边界

**适用条件**　文本列共享索引且使用等宽字符时

**如何应用**　先固定量纲和读序，仅将视觉层按列组合；测量每帧开销。

**代价**　比例字、换行或双向文本条件下不宜直接沿用轨道假设。

**库中反例或不适用场景**　对动态混排富文本逐字符强制使用同一角宽。
