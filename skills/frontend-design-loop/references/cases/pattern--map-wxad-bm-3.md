# 用可调转盘识别手感差异

`pattern/map-wxad-bm-3` · ORIGINAL_PRACTICE · 上游复核状态 pending

**来源定位**　[转盘交互动画](https://wxad.design/abc/bm)

**案例或原则（UI Lab 的来源笔记）**　评选项目将转盘的手势与收尾拆成可调整参数，比较逐张浏览和快速滑动。

## UI Lab 扩写与适用边界

**适用条件**　需要快速比较动量、阻尼和逻辑边界时

**如何应用**　固定内容和视口，每轮只调整一个物理参数并记录端点、轨迹、重抓。

**代价**　参数比较可解释差异，仍需要目标用户验证。

**库中反例或不适用场景**　一次同时调快跟手、调大滑行、加回弹，无法判断改善从何而来。
