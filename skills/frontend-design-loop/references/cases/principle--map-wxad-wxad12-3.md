# 放大后仍是同一个可操作对象

`principle/map-wxad-wxad12-3` · ORIGINAL_PRACTICE · 上游复核状态 pending

**来源定位**　[时钟转盘](https://wxad.design/abc/wxad12)

**案例或原则（UI Lab 的来源笔记）**　活动用可追踪秒针连接时钟与放大后的照片转盘，强调用户仍在操纵原对象。

**为什么这样做**　保留稳定视觉标识和输入方向，先测试快速反向和回到概览。

## UI Lab 扩写与适用边界

**适用条件**　视图变换但操作对象和方向需要保持时

**如何应用**　保留稳定视觉标识和输入方向，先测试快速反向和回到概览。

**代价**　共享身份要求布局源可测量，并给触控拖拽留出空间。

**库中反例或不适用场景**　进入详情后突然反转手势方向，用明显相同的外壳暗示行为不变。
