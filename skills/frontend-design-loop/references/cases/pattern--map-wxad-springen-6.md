# 同组目标共用一个 HoverFill

`pattern/map-wxad-springen-6` · ORIGINAL_PRACTICE · 上游复核状态 pending

**来源定位**　[共享背景](https://wxad.design/abc/springen)

**案例或原则（UI Lab 的来源笔记）**　作者在相邻同父元素间共享背景，目标变更时沿用同一可见对象。

## UI Lab 扩写与适用边界

**适用条件**　同组轻量动作够近且强调只有一个瞬时目标时

**如何应用**　以显式交互组管理指针、焦点和触控目标；更新几何位置时保持同一层。

**代价**　自动按 DOM 邻近分组会误合并，移出整组与跨项切换要分开。

**库中反例或不适用场景**　对支持多选和并行高亮的项目共用唯一一个选中背景。
