# 使用回弹表达落点确认

`interaction/map-wxad-carousel-5` · ORIGINAL_PRACTICE · 上游复核状态 pending

**来源定位**　[是否需要回弹？](https://wxad.design/abc/carousel)

**案例或原则（UI Lab 的来源笔记）**　作者给无物理边界的转盘加入轻度回弹，用于强化选中落定。

**原条目中的触发场景**　需要明显确认已对齐的轮播停点时

## UI Lab 扩写与适用边界

**适用条件**　需要明显确认已对齐的轮播停点时

**如何应用**　在吸附结束用一次小幅欠阻尼收束，拖拽重入时先取消收尾。

**代价**　更强的确认也会增加停稳时间。

**库中反例或不适用场景**　快速刷选名单时每次都大幅回弹，导致连续选择拖沓。
