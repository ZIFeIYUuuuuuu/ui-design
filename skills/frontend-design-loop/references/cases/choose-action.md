# 在卡片、工具栏或确认区辨认主要和独立操作

只选能解释当前选择的一条。以下走查与判断分支为本次移植的教学例题，可按产品任务调整。

**怎么走**　在一张有主入口和更多按钮的卡里，分别触发卡和菜单，再取消；进入批量模式重复观察。

**怎样根据现场选择**　业务动作不同就保留独立反馈；等价次操作才考虑共享层。能识别主命令且误触成本低，可以保持。
