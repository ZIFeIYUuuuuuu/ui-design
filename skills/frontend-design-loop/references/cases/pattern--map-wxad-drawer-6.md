# 为抽屉手势定义分支和停点

`pattern/map-wxad-drawer-6` · ORIGINAL_PRACTICE · 上游复核状态 pending

**来源定位**　[滑动交互](https://wxad.design/abc/drawer)

**案例或原则（UI Lab 的来源笔记）**　抽屉对越界拖动以及释放时的运动方向和强弱分别处理，也可以提供多个停靠位置。

## UI Lab 扩写与适用边界

**适用条件**　同一张桌面或地图面板需要多档可见高度时

**如何应用**　明确拖拽、释放、取消、停靠状态；内容可滚动时先判定滚动归属。

**代价**　多个停点增加状态和手势冲突，移动端软键盘还会改变可视高度。

**库中反例或不适用场景**　简单确认弹窗需要清晰的确定与取消，却只能靠多档滑动完成。
