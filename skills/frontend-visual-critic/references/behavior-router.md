# 按行为找案例 / Route by behavior

先写一句：用户正在对什么对象做什么，哪一个设计选择需要判断？从下表选一行，再只打开其中最匹配的一张案例卡。同一控件在不同动作下可以进入不同分支。跨任务交接沿用已读案例；若没有匹配项，写明本次推导及验证办法。全站审查仍覆盖所有可执行路径和不同控件。

| 用户正在做什么 | 需要辨别什么 |
|---|---|
| [指针扫过相邻目标，想辨认用途或预览下一项](cases/browse-targets.md) | 首次提示、跨项宽限、出组清理、悬停背景与多选 |
| [按下、松开、确认提交或切换模式](cases/activate.md) | 指针预反馈、持久选中、计数与业务受理 |
| [从触发点打开、切换或关闭菜单／对话框](cases/open-overlay.md) | 浮层锚点、空间边界、焦点归还、嵌套弹层 |
| [拖动面板，同时滚动其中的内容或输入文字](cases/drag-panel.md) | 手势归属、停靠点、释放、软键盘 |
| [拖、甩、转动、调整范围或比较两个值](cases/manipulate.md) | 释放速度、回弹、吸附、滑块重叠与比较图 |
| [切换视图、展开列表，从卡片进详情再返回](cases/navigate.md) | 对象身份、滚动位置、当前导航、展开边界 |
| [增加、删除、排序，收到一条或多条通知](cases/update.md) | 退出时机、通知堆、确认、空数据和权限 |
| [重复操作、动画未完就反向，或开启减少动态](cases/interrupt.md) | 频率、中断、运动曲线、性能与静态替代 |
| [在卡片、工具栏或确认区辨认主要和独立操作](cases/choose-action.md) | 命中区域、风险、按钮主次、操作密度 |
| [辨认选中、焦点、禁用或错误；在主题色上读文字](cases/read-state.md) | 状态配色、非颜色线索、实际前景背景、色阶 |
| [读取、搜索、填写或比较密集信息](cases/scan.md) | 名称与值、表单分组、表格扫描、排版与宽度 |
| [在叠层、输入区或图像表面识别可操作内容](cases/surface.md) | 高程、边界、裁切、媒体与文字的局部对比 |
| [比较方案或校准产品语言，手头没有直接对应的组件案例](cases/evaluate.md) | 真实任务、可复验证据、来源和方案边界 |

找不到分支时，可按动作或状态关键词在 component-rule-index.md 中定位条目。该完整索引仅作查找备用。交接时带上案例 ID、适用条件、实际观测与复验动作，同一行为不用重复读取。
