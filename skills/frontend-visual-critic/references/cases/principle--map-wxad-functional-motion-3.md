# 切换顶级导航时保留浮层外壳

`principle/map-wxad-functional-motion-3` · ORIGINAL_PRACTICE · 上游复核状态 pending

**来源定位**　[优雅的下拉导航：NavigationMenu](https://wxad.design/abc/functional-motion)

**案例或原则（UI Lab 的来源笔记）**　相邻导航项之间可延续同一浮层并换内容，以维持浏览连续性。

**为什么这样做**　分开当前目标、已挂载的浮层和内容；焦点进出与指针离开整组分别处理。

## UI Lab 扩写与适用边界

**适用条件**　同级导航项共享一个次级链接展示区时

**如何应用**　分开当前目标、已挂载的浮层和内容；焦点进出与指针离开整组分别处理。

**代价**　复用浮层要求正确替换读屏内容和焦点归属。

**库中反例或不适用场景**　多个可以同时打开的独立工具菜单被强制共享唯一外壳。
