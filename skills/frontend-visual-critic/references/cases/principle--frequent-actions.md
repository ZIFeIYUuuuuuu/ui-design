# 高频入口减少过渡

`principle/frequent-actions` · ORIGINAL_PRACTICE · 上游复核状态 pending

**来源定位**　[Frequency of use](https://emilkowal.ski/ui/you-dont-need-animations)

**案例或原则（UI Lab 的来源笔记）**　高频打开的界面可以即时呈现，避免重复播放进入动效。

**为什么这样做**　单次可接受的时长在每天重复触发时也会累积摩擦。

## UI Lab 扩写与适用边界

**适用条件**　快捷搜索；经常反复打开的工作台控件

**库中反例或不适用场景**　状态变化缺少其他明确提示的操作
