**案例或原则（UI Lab 的来源笔记）**　比例字形需要不同间距，正文示例让父元素统一监听布局尺寸变化。

## UI Lab 扩写与适用边界

**适用条件**　环形标题使用可变语言或可后加载字体时

**如何应用**　收集实际字宽并按弧长分布，合并 resize 通知，同步保留线性可读文本。

**代价**　逐字定位增加维护成本，缩放后还需检查间距和语义。

**库中反例或不适用场景**　按英文等宽字符均分旋转角度，换用比例字或中文后相邻字重叠。
