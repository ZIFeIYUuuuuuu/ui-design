# 释放速度决定惯性距离

`principle/map-wxad-carousel-3` · ORIGINAL_PRACTICE · 上游复核状态 pending

**来源定位**　[松开手指后，应该停在哪？](https://wxad.design/abc/carousel)

**案例或原则（UI Lab 的来源笔记）**　松手时采样速度并乘可调系数，控制惯性距离以兼顾细看和快扫。

**为什么这样做**　把速度换算到同一时间单位，再把预测落点吸附到可选项，重抓时接手当前角度。

## UI Lab 扩写与适用边界

**适用条件**　连续轮播或可快速浏览的选择集合

**如何应用**　把速度换算到同一时间单位，再把预测落点吸附到可选项，重抓时接手当前角度。

**代价**　过高的系数会跨过目标，过低时快速滑动失去意义。

**库中反例或不适用场景**　精确输入一位数时按甩动速度跳过多个选项。
