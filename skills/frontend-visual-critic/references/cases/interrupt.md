# 重复操作、动画未完就反向，或开启减少动态

只选能解释当前选择的一条。以下走查与判断分支为本次移植的教学例题，可按产品任务调整。

**怎么走**　动作未结束就反向，普通与减少动态各重放一次。对照中间态、响应延迟和最后业务状态。

**怎样根据现场选择**　若中途还能操作且状态清楚，保留；若输入被动画锁住，允许接手；仅有装饰收益时比较静态版本。
