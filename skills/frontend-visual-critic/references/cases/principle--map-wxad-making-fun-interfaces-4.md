# 让确认页的视觉重点回到动作

**来源定位**　[确认](https://wxad.design/abc/making-fun-interfaces)

**案例或原则（UI Lab 的来源笔记）**　作者减弱投票确认气泡的色彩和高亮，让底部按钮成为下一步入口。

**为什么这样做**　保持内容可读，用更小的对比和更少的运动给次要提示降权。

## UI Lab 扩写与适用边界

**适用条件**　需要在结果预览中明确唯一下一步时

**如何应用**　保持内容可读，用更小的对比和更少的运动给次要提示降权。

**代价**　过度褪色可能丢失被选中的语义或文字对比。

**库中反例或不适用场景**　所有选项、装饰和主按钮用同样高饱和度闪动。
