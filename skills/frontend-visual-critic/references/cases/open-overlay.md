# 从触发点打开、切换或关闭菜单／对话框

只选能解释当前选择的一条。以下走查与判断分支为本次移植的教学例题，可按产品任务调整。

**怎么走**　从贴近边缘的触发器打开，换输入方式，再 Esc 关闭；嵌套时先关闭内层。

**怎样根据现场选择**　若归属、位置和返回目标均明确，可保留静态开合；遮挡主操作时先避让边界；关闭后失焦先修返回路径。
